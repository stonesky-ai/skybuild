# Atomic task split slice

This slice adds `POST /api/v1/projects/{project_id}/tasks/{task_id}/split` and a lineage read route. It is for isolated task development. The imported SkyBuild project remains read-only while Markdown is authoritative; this route does not switch authority or start work.

Split requires an expected revision, idempotency key, reason, 2–10 new child tasks, and an explicit incoming dependency map for every task that depends on the source. Each child supplies title, full description, acceptance criteria and dependencies. The children together must retain every source acceptance criterion and prerequisite. The map must name every incoming dependent and assign it to at least one child. No edge is inferred from prose. Children inherit source priority. A single PostgreSQL transaction locks the project graph, creates children, validates dependencies and cycles, rewires dependents, records immutable task history/lineage, and marks the source `superseded`. A replay with the same request returns the original result. Conflict or failure rolls back all changes.

Until durable attempt/effect reconciliation exists, split accepts only a proposed source and proposed dependents with no history showing work or completion. This deliberately excludes blocked, deferred, active, completed and previously started tasks. Replaced IDs remain in the task table and immutable history; normal edits/actions cannot revive a superseded task. Split is one bounded structural operation. Merge, arbitrary acceptance reallocation, active-effect reconciliation and workbench split controls remain open before the full structural workflow is complete.

Separate `split_review` found one safety gap: a blocked task might have been in progress before rework, with uncertain effects. The author added proposed-only and execution-history checks, plus refusal tests for a reworked started source and blocked dependent. The reviewer accepted the correction. The full disposable PostgreSQL suite passed 130 tests with one existing upstream Starlette TestClient deprecation warning. Migration 004 adds the superseded status and immutable lineage table.
