# Manual task workflow slice

This launch-free slice adds guarded task actions on disposable projects while Markdown remains the live SkyBuild task authority. `POST /api/v1/projects/{project_id}/tasks/{task_id}/actions/{action}` accepts `rework`, `reassess`, `defer` or `resume`, with a reason, `If-Match` revision and idempotency key. Each accepted action updates the task, increments its workflow generation and appends an immutable actor/reason/before/after event in one transaction. It does not admit or launch work.

Creation starts in proposed triage. Generic PATCH still edits ordinary definition fields and dependencies, but cannot set status, phase or blocker directly. The `_skybuild_workflow` metadata key is managed by Store. A definition edit after a workflow action increments its generation, clears a pending deferral and marks the task blocked for reassessment. This is a conservative invalidation; later check/review/bundle evidence is not implemented yet.

Deferral requires exactly one timezone-aware future date or existing unfinished milestone task. Re-deferral changes the trigger while retaining the originally interrupted phase. Resume sends the task to blocked reassessment, retaining its prior phase in history; it does not infer readiness. A CPU-only `reconcile_due_deferrals` operation scans one bounded ordered page and journals a resume to reassessment when a date is due or a milestone is done. The workbench scans pages when the owner presses “Reassess due deferrals.” No timer, model call or automatic worker is enabled. Scheduling catch-up after a laptop restart, broader evidence-based phase selection, guarded completion, split/merge lineage, structural dependency rewiring and active-effect reconciliation remain to build before automatic adoption.

The independent `workflow_review` session challenged direct PATCH bypass, already-reached triggers, resume phase loss, two deferral-cycle mistakes and workbench pagination. The author corrected each; focused and full tests were rerun, and the reviewer accepted the final two-cycle correction. Final full suite: 125 passed with the existing Starlette TestClient deprecation warning. These results validate the manual slice against disposable PostgreSQL, not production task authority.
